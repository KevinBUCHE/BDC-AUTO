Usage rapide (fichiers à fournir)
==================================
1) Template officiel : placez le PDF « bon de commande V1.pdf » dans le dossier `Templates/` à la racine.
2) Devis SRX : choisissez votre devis PDF via l’interface (ou déposez-le sur RUN.bat si vous utilisez le portable). Optionnel pour tests manuels : stockez-les dans `samples/` (non versionné).
3) Configuration (liste noire, dépôt, chemins) : ajustez `config.json` ou `Config/config.json` selon votre installation.

Fonctionnement
--------------
- L’application nécessite le template dans `Templates/`. S’il manque, un message demande de le déposer.
- Les BDC générés et JSON debug se trouvent dans `Output/`.
